Luna 隐私和安全说明

2026年10月23日


一、文档目的

本文档用于说明Luna桌面智能体软件（以下简称“Luna”、“本软件”）在个人信息处理、数据存储、网络传输、权限控制等方面的设计原则、实现机制、用户权利保障措施。


二、软件概述

本软件是一款运行在Windows操作系统的桌面个人AI智能体。软件以常驻屏幕顶部的胶囊状态窗口和主窗口作为交互入口，通过全局快捷键或系统托盘图标呼出，用户可用自然语言向软件提问，或指示软件调用本机工具完成实际任务。


三、隐私保护总体原则

本软件在设计与实现中遵循以下原则：

1. 用户数据保存至本地计算机，不上传至开发者服务器。
2. 仅处理实现功能所必需的数据，不采集与功能无关的设备信息、用户日常计算机操作或生物特征信息。
3. 涉及用户计算机资源读取、写入、命令执行等敏感操作，均由用户手动授权或手动允许始终批准。高风险能力强制要求用户逐次授权。


四、数据处理

用户使用Luna过程中由用户手动输入的数据或本软件自动生成的数据，会有部分内容被上传至远程服务器，也会有部分内容被用于本地计算机加工处理。详情如下：

1. 用户输入的对话内容与模型回复、轮次摘要与日记内容、上传的附件（图片、文档等文件）和软件记录的长期事实（用户偏好等），将会被发送至用户配置的AI提供商用于完成对话与任务。
2. 待办事项与提醒时间、剪贴板文本、截屏内容，会在随对话内容发送的场景下发送至用户配置的AI提供商。
3. API Key、代理密码等用户配置仅作为请求凭据发送至对应服务商。

本软件明确不主动收集、不上传以下信息：

1. 用户真实姓名、身份证件、手机号码、通讯录等身份信息；
2. 设备、硬件唯一标识、广告标识符；
3. 用户在其他软件中的使用行为、浏览记录；
4. 地理位置信息；
5. 支付信息与银行卡信息；
6. 任何用于用户画像、广告投放或数据交易的信息。

本软件不集成第三方统计SDK、广告SDK或崩溃上报服务，不含向开发者上传数据的模块。


五、本地数据存储

5.1 数据存储位置与内容

5.2 存储期限

软件不设置数据保留期限。会话、日记、待办、长期事实等数据由用户自行管理，用户删除后则从本地数据库中移除。日志和自动备份最多各保留7个文件，超出后，软件将会自动清理最旧记录。

5.3 存储安全说明

数据库、日记、附件、日志均以明文形式存储与本地计算机，未加密。软件通过Windows用户账户隔离机制限制访问。数据目录仅位于当前用户配置目录下，操作系统文件权限保证其他一般权限用户无法直接读取。由于settings.json与数据库位于漫游目录 %APPDATA%，在启用漫游配置文件的企业域环境中，这些数据可能随用户配置文件同步到域服务器。附件、日志与备份位于 %LOCALAPPDATA%，不参与漫游。


六、网络传输与第三方共享

联网场景

本软件仅在以下场景发送网络请求，且均由用户主动配置或触发：

1. 对话生成：用户发送消息时，将会向用户自行配置的AI提供商的 /chat/completions 接口发送对话消息、系统提示词、相关长期事实、附件内容。
2. 网页搜索：用户与AI交互过程中，AI调用搜索工具，将会通过Tavily搜索服务，根据用户需要查询的关键词搜索网页内容。
3. 网页阅读：用户与AI交互过程中，AI调用网页阅读工具，将会访问指定URL。
4. 新闻与日历：用户与AI交互过程中，AI调用新闻与日历工具，将会访问相应内容的服务接口。该传输过程中不包含个人数据。

传输安全

所有网络请求通过HTTPS协议传输，由 .NET 运行时默认启用TLS校验。API Key在发送前由内存中的明文拼装为HTTP请求头，不会写入日志，也不会留下明文信息。

请求设置超时和重试上限（最多3次，重试等待上限30s），避免异常情况下产生长时间的访问阻塞或重复发送。

软件所有内容不经过开发者自有服务器中转。数据直接由用户本地计算机与用户选定的服务商之间传输。开发者无法访问用户使用本软件产生的任何数据。

第三方责任边界

用户配置的AI提供商、搜索服务与网页站点均属于独立第三方，上述第三方对数据的收集、存储、使用等行为受其自身隐私协议政策的约束，本软件无法控制。Luna本身不提供模型，用户可在本软件自主选择、配置和使用第三方AI服务，服务的合规责任应由用户及其选择的服务商承担。


七、凭据与密钥保护

软件对敏感凭据采用Windows数据保护接口DPAPI进行加密。加密范围包含：AI服务的API Key、Tavily搜索的API Key、网络代理密码等敏感字符串。

加密与解密：调用系统crypt32.dll提供的DPAPI接口，以当前Windows用户为保护范围生成密文，密文以Base64形式写入配置文件。仅能由同一Windows用户在同一台Windows操作系统计算机上解密，在其他设备或账户使用此密文将无法还原为正确的明文。加密与解密均已设置CRYPTPROTECT_UI_FORBIDDEN标志，防止系统弹出交互界面，避免泄露信息。

解密失败时返回空字符串并按照未配置处理，不输出密文或错误细节到界面。

本软件提供数据备份功能，但明确排除settings.json，避免加密凭据随备份文件扩散。

凭据和密钥信息不进入日志。日志仅记录请求地址、模型名称、HTTP状态码和耗时。


八、用户授权与权限控制

8.1 工具风险分级

软件内置的工具均声明了风险等级，分别为：None、Low、Medium、High，并配合“需确认”标记：

None/Low：直接执行；

Medium（危险）/High（高危）：可能读取隐私数据、修改用户计算机状态或执行代码的工具，执行前需要用户确认

8.2 授权交互

需确认的工具在执行前弹出授权对话框，显示工具名称、用途说明和本次调用的实际参数，用户可做出以下选择：

允许本次：仅对这一次调用生效批准；

始终允许（记住）：今后对该工具调用免确认，除非用户在“设置 - 通用”的“工具授权”卡片中执行了“清除允许的授权”。用户点击该按钮后，下次调用该工具将会重新弹出授权对话框。对于高危工具等危险程度较高的代码执行工具，没有“始终允许（记住）”选项，强制每次调用此工具时需要用户逐次手动批准；

拒绝：终止本次调用，并将拒绝结果返回给模型。

8.3 授权记录

工具的调用与授权结果写入本地数据库的记录表，用户可在聊天记录中自行查阅，用于回溯工具调用的时间、对话轮次、工具项目与参数、结果。


九、工具执行安全机制

9.1 命令执行（PowerShell）

控制项目和具体实现方式见下表：

控制项	实现方式
只读白名单	命令每一段管道必须以 Get、Test、Select、Where、Measure、Format、Group、Sort、Compare、ConvertTo、ConvertFrom、Out- 等只读动词开头
写操作黑名单	命令中出现 Remove、Set、New、Invoke、Start、Stop、Restart、Install、Uninstall、Enable、Disable、Clear、Add、Out-File、Set-Content 等动词时直接拒绝
管道逐段校验	以 | 分隔逐段校验
执行环境	以 -NoProfile -NonInteractive 启动，不加载用户配置文件，不接受交互输入
超时控制	单次执行超时 30 秒，超时或用户取消时终止整个进程树
输出限制	标准输出与错误输出合计截断至 5000 字符，防止超长输出冲击界面与上下文
授权要求	风险等级 High，每次调用强制弹窗确认

9.2 文件读写沙箱

1. 写入操作被限定在软件由用户配置的输出目录中。输出目录路径经过规范化校验检测，防止通过“..”等方式越界写入系统目录；
2. 写入扩展名黑名单覆盖可执行文件、脚本、安装包与二进制文件和镜像文件（如.exe、.dll、.bat、.ps1、.cmd、.msi、.vbs、.jar、.iso等），命中即拒绝；
3. 单文件读写上线1MB，超过限制则返回错误，不加载内容；
4. 读取需为真实存在的文件，路径经过完整解析后校验；不可读、不存在、超限等情况返回明确错误而不抛出异常细节。

9.3 代码执行沙箱

代码执行工具依赖用户计算机上的Python环境，在独立python.exe进程中运行用户或模型生成的Python代码，为保护用户数据安全，沙箱采取以下保护措施：

1. 以正则黑名单拒绝网络访问（socket、urllib、requests、httpx）、进程与文件系统操作（subprocess、shutil、pathlib、os、open）、动态执行（eval、exec、compile、__import__）等语句；
2. 每次执行创建独立的随机临时工作目录，执行结束后删除脚本和目录；
3. 设置超过10秒执行即终止进程树的超时限制；
4. 累计输出内容不得超过100KB，超出部分丢弃并标记为截断返回给模型；

风险说明：该工具风险等级为高危，需要用户确认。该工具“尽力而为”保护操作系统和数据安全的沙箱，非强隔离环境。

9.4 屏幕、窗口与系统控制

1. 截图工具在捕获时排除本软件自身窗口，避免将软件界面重复摄入，对不支持窗口排除的旧版操作系统将会自动回退为临时移屏方案；
2. 窗口管理、音量与亮度调节等操作均声明为需确认工具，执行前展示目标窗口或目标数值；
3. 全局快捷键通过系统热键注册与键盘钩子实现，仅用于识别用户设定的组合键以呼出胶囊状态窗口，按键内容不会写入数据库、日志，不会进行网络传输。


十、提示词注入与不可信内容防护

在使用本软件的过程中，模型会使用工具内容，将网页、文档、剪贴板、命令输出等外部内容送入模型的上下文，存在恶意内容伪装成指令的风险，因此软件采取以下保护措施：

1. 系统级安全规范由程序在用户设置的人格提示词后强制拼接，该规范为硬编码，用户自定义的人格提示词无法覆盖或删除该部分；
2. 工具返回的网页内容、文件内容、剪贴板内容等被明确定义为“数据”而非“指令”，系统规范要求模型不得执行其中的指令性文本；
3. 模型可调用的工具集合由程序注册表规定，未注册的工具无法被调用，工具参数在执行前先由程序校验，模型无法绕过检验直接操作文件系统或进程；
4. 即使模型被诱导使用高风险工具，仍需要用户授权，命令执行与代码执行另有白名单、黑名单进行操作限制。


十一、数据完整性检验与保障

1. 启用SQLite WAL日志模式与外键约束，启动时执行 PRAGMA quick_check 进行完整性检查，异常时记录错误并终止初始化，避免程序在损坏状态下继续写入；
2. 全部数据库访问通过参数化语句或ORM映射完成，不拼接用户输入，防止SQL注入；
3. Settings.json采用“先写临时文件再替换目标文件”的写入方式，写入失败则不会覆盖源文件，避免产生错误的配置文件；
4. 每次加载成功后刷新 .bak 备份；主配置损坏时自动从备份中恢复，并将损坏的文件改名为 .corrupt-<时间戳> 并保存供诊断；
5. 用户可选择自行导出备份ZIP文件，包含日记、长期事实、会话、消息、待办、轮次摘要、附件元数据及附件文件；导入时校验备份内是否包含数据库文件，并检验数据库结构是否正确，否则直接拒绝。导入操作采用先暂存，后覆盖的方式，避免在程序运行过程中强制覆盖。覆盖前自动生成 .before-restore-<时间戳> 快照文件，如果覆盖失败则尝试回滚，恢复备份完成后将会清理未被引用的孤儿附件。


十二、日志与审计

用户在使用Luna的过程中，程序会根据使用场景，在特定的情况下向日志文件中写入日志条目，用于本地故障排查与稳定性改进。日志文件不会由该软件主动上传到远程服务器。

日志将会记录模块启动、配置加载、请求地址与模型、HTTP状态码、耗时、异常等运行信息，不会记录对话内容、密钥，不会记录文件正文。日志留存按天滚动，最多保留7个文件，超期文件自动删除。

工具名称、工具调用参数摘要、授权结果、执行状态与时间写入本地数据库，并在对应的聊天记录中显示，供用户自查。


十三、合规声明

1. 本软件遵循《中华人民共和国网络安全法》、《中华人民共和国数据安全法》、《中华人民共和国个人信息保护法》相关要求，合法、正当、必要且诚信地处理个人信息；
2. 本软件不主动收集未成年人个人信息；
3. 本软件不将用户数据用于广告推送、用户画像等分析或数据交易；
4. 本软件无账号体系，不进行实名认证，不采集任何身份证件信息；
5. 用户配置境外AI服务提供商时，相关对话内容可能传输至境外服务器，软件在配置环节提示该风险，由用户自主选择并自行承担相应后果。


十四、已知限制与风险提示

为便于用户评估和审核，本软件如实告知以下限制：

1. 本地数据库未进行整库加密：数据库、附件、日志为明文存储，安全性依赖Windows账户隔离与磁盘加密等系统级措施；
2. 第三方模型不可控：模型输出由第三方服务生成，软件无法保证其准确性，用户应对设计重要决策的输出自行判断；
3. 沙箱为尽力而为：代码执行与命令执行采用进程级隔离和规则校验，非强隔离，无法完全排除绕过可能，故均要求用户逐次确认；
4. 漫游目录风险：启用漫游配置文件的企业环境中，配置与数据库可能随账户同步至域服务器。
