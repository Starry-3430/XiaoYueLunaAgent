Luna 智能助手软件 V1.0 隐私和安全说明

文档版本 V1.0
2026年10月24日


一、文档目的

本文档用于说明Luna桌面智能体软件（以下简称“Luna”、“本软件”）在个人信息处理、数据存储、网络传输、权限控制等方面的设计原则、实现机制、用户权利保障措施。


二、软件概述

本软件是一款运行在Windows操作系统的桌面个人AI智能体。软件以常驻屏幕顶部的胶囊状态窗口和主窗口作为交互入口，通过全局快捷键或系统托盘图标呼出，用户可用自然语言向软件提问，或指示软件调用本机工具完成实际任务。


三、隐私保护总体原则

本软件在设计与实现中遵循以下原则：

1. 用户数据保存至本地计算机，不上传至开发者服务器。
2. 仅处理实现功能所必需的数据，不采集与功能无关的设备信息、用户日常计算机操作或生物特征信息。
3. 工具按风险等级控制授权：None/Low 工具可直接执行；Medium/High 工具执行前需要用户确认。仅白名单中的只读工具允许用户选择“始终允许（记住）”；高风险工具（包括 PowerShell、Python 代码执行、窗口管理、音量/亮度控制等）不提供始终免确认的选项，每次调用均需用户手动批准。
4. 完全访问模式（见 9.5）是用户主动开启的高风险模式。该模式仅解除工具自身的内容限制，不改变授权规则：Medium/High 风险工具仍需用户手动确认。PowerShell 和 Python 代码执行仍不提供“始终允许（记住）”。该功能启用后全局生效，用户可通过点击聊天区右下角的“⚠完全访问”红色标记，或“设置 - 调试”关闭完全访问按钮手动关闭该模式。


四、数据处理

用户使用Luna过程中由用户手动输入的数据或本软件自动生成的数据，会有部分内容被上传至远程服务器，也会有部分内容被用于本地计算机加工处理。详情如下：

1. 用户输入的对话内容与模型回复、轮次摘要与日记内容、上传的附件（图片、文档等文件）和软件记录的长期事实（用户偏好等），将会被发送至用户配置的AI提供商用于完成对话与任务。
2. 待办事项与提醒时间、剪贴板文本、截屏内容，只有在模型调用相应工具、相关数据进入对话上下文并随请求发送给 AI 提供商时，才会被一并发送。
3. API Key、代理密码等用户配置仅作为请求凭据发送至对应服务商。

完全访问模式下，AI 生成的 Python 代码和 PowerShell 命令可自行访问网络和任意文件，此时数据的发送不再经过本软件的网络模块，也不在第六章所列场景之内。软件将无法限制、记录或拦截此类行为。

本软件明确不主动收集、不上传以下信息：

注：以下承诺仅针对本软件自身行为。完全访问模式下由AI生成的代码或命令发起的数据外发属于用户主动授权后的行为，不在承诺范围内。

1. 用户真实姓名、身份证件、手机号码、通讯录等身份信息；
2. 设备、硬件唯一标识、广告标识符；
3. 用户在其他软件中的使用行为、浏览记录；
4. 地理位置信息；
5. 支付信息与银行卡信息；
6. 任何用于用户画像、广告投放或数据交易的信息。

本软件不集成第三方统计SDK、广告SDK或崩溃上报服务，不含向开发者上传数据的模块。

5.2 存储期限

软件不设固定保留期限，会话、日记、待办、长期事实等数据由用户自行管理，用户删除后即从本地数据库移除；日志与自动备份按数量上限自动清理（各 7 份）。完全访问开关状态随 settings.json 保存，不设自动失效期限。

5.3 存储安全说明

数据库、日记、附件、日志均以明文形式存储于本地计算机，未加密。软件通过Windows用户账户隔离机制限制访问。数据目录仅位于当前用户配置目录下，操作系统文件权限保证其他一般权限用户无法直接读取。由于settings.json与数据库位于漫游目录 %APPDATA%，在启用漫游配置文件的企业域环境中，这些数据可能随用户配置文件同步到域服务器。附件、日志与备份位于 %LOCALAPPDATA%，不参与漫游。

完全访问模式不改变上述存储方式，但会解除工具层的目录与扩展名限制：AI 可读取、修改或删除本软件自身的数据目录（数据库、日志、附件、备份、settings.json 密文）。DPAPI 仍保护密钥明文，但在同一 Windows 用户上下文中密文可被解密使用。账户隔离与磁盘加密是该模式下主要的系统级边界。

六、网络传输与第三方共享

6.1 联网场景

本软件仅在以下场景发送网络请求，且均由用户主动配置或触发：

1. 对话生成：用户发送消息时，将会向用户自行配置的AI提供商的 /chat/completions 接口发送对话消息、系统提示词、相关长期事实、附件内容。
2. 网页搜索：用户与AI交互过程中，AI调用搜索工具，将会通过Tavily搜索服务，根据用户需要查询的关键词搜索网页内容。
3. 网页阅读：用户与AI交互过程中，AI调用网页阅读工具，将会访问指定URL。
4. 新闻与日历：用户与AI交互过程中，AI调用新闻与日历工具，将会访问相应内容的服务接口。该传输过程中不包含个人数据。
5. 连接测试：用户在欢迎向导或设置中点击“连接测试”时，向当前配置的AI服务地址发送一次最小的对话请求，用于验证地址、模型和密钥是否可用。
6. 更新检查：用户主动检查更新时，访问 GitHub Releases API 或 releases.atom；用户确认更新后，从 GitHub Releases 下载安装包及 SHA-256 校验文件。
7. 代理连通性测试：用户点击“测试代理”时，通过当前代理访问 https://www.baidu.com，仅用于验证代理是否可用，不包含用户数据。

6.2 完全访问模式下的网络行为

启用完全访问后，代码执行工具不再拦截 socket、urllib、requests、httpx 等模块，PowerShell 也不再限制 Invoke-* 等动词，AI 生成的代码或命令可以自行建立任意网络连接（含非 HTTP 协议与非标准端口）。这类连接：

1. 不经过本软件的 HttpClient，不受第七章的 HTTPS 约束、代理设置、超时与重试策略约束；
2. 不出现在 6.1 的联网场景清单中，也不受本软件审计；
3. 可能将本机文件内容、剪贴板、截图、数据库内容发送至任意地址。

上述行为由用户在开启完全访问时一次性授权，软件不再逐次提示。

6.3 传输安全

内置服务端点（包括内置 AI 提供商预设、Tavily、BBC RSS 和 GitHub Releases）均使用 HTTPS 传输。HttpClient 未关闭 .NET 默认的 TLS 证书校验，也未实现自定义证书绕过。

1. AI 的 Base URL 由用户自行填写，程序会直接拼接并请求该地址；如果填写 http:// 地址，对话内容和 API Key 将以明文传输。
2. 网页阅读工具接受 http:// 和 https:// 地址；HttpClient 默认允许自动重定向，HTTPS 页面也可能被重定向到 HTTP。
3. 如用户配置 HTTP/SOCKS 代理，网络流量还会经过该代理转发。

API Key 在发送前由内存中的明文拼装为 HTTP 请求头，不会写入日志，但会随请求发送给用户配置的服务商；只有使用 HTTPS 时，传输过程才具备保密性。

AI 对话请求设置了总超时、响应头超时和流式空闲超时，并对可重试错误最多尝试 3 次，重试等待上限为 30 秒。网页搜索、网页抓取、新闻、更新检查和连接测试各自设置了超时，但没有统一实现 3 次重试。

软件不运营开发者自有服务器中转。除用户配置的第三方服务以及 GitHub 更新检查/下载外，数据由用户本地计算机直接发送至对应服务；如用户配置了代理，则请求经用户指定的代理转发。开发者无法访问用户使用本软件产生的数据。

6.4 第三方责任边界

用户配置的AI提供商、搜索服务、网页站点、GitHub（更新检查/下载）以及代理测试目标站点均属于独立第三方，上述第三方对数据的收集、存储、使用等行为受其自身隐私协议政策的约束，本软件无法控制。Luna本身不提供模型，用户可在本软件自主选择、配置和使用第三方AI服务，服务的合规责任应由用户及其选择的服务商承担。


七、凭据与密钥保护

软件对敏感凭据采用Windows数据保护接口DPAPI进行加密。加密范围包含：AI服务的API Key、Tavily搜索的API Key、网络代理密码等敏感字符串。

加密与解密：调用系统crypt32.dll提供的DPAPI接口，以当前Windows用户为保护范围生成密文，密文以Base64形式写入配置文件。仅能由同一Windows用户在同一台Windows操作系统计算机上解密，在其他设备或账户使用此密文将无法还原为正确的明文。加密与解密均已设置CRYPTPROTECT_UI_FORBIDDEN标志，防止系统弹出交互界面，避免泄露信息。

解密失败时返回空字符串并按照未配置处理，不输出密文或错误细节到界面。

本软件提供数据备份功能，但明确排除settings.json，避免加密凭据随备份文件扩散。

凭据和密钥信息不进入日志。日志仅记录请求地址、模型名称、HTTP状态码和耗时。

完全访问模式下，AI 可读取 settings.json 中的密文，并可在同一 Windows 用户上下文中调用 DPAPI 解密；也可读取、篡改或删除日志、数据库与审计记录。因此该模式下的凭据与审计保护强度低于常规模式。


八、用户授权与权限控制

8.1 工具风险分级

软件内置的工具均声明了风险等级，分别为：None、Low、Medium、High，并配合“需确认”标记：

None/Low：直接执行；
Medium（危险）/High（高危）：可能读取隐私数据、修改用户计算机状态或执行代码的工具，执行前需要用户确认。

8.2 授权交互

需确认的工具在执行前弹出授权对话框，显示工具名称、用途说明和本次调用的实际参数，用户可做出以下选择：

允许本次：仅对这一次调用生效批准；
始终允许（记住）：今后对该工具的调用免确认，除非用户在“设置 - 通用”的“工具授权”卡片中执行了“清除允许的授权”。用户点击该按钮后，下次调用该工具将会重新弹出授权对话框。对于代码执行等危险程度较高的工具，没有“始终允许（记住）”选项，强制每次调用此工具时需要用户逐次手动批准；
拒绝：终止本次调用，并将拒绝结果返回给模型。

8.3 授权记录

工具的调用与授权结果写入本地数据库的记录表，用户可在聊天记录中自行查阅，用于回溯工具调用的时间、对话轮次、工具项目与参数、结果。


九、工具执行安全机制

9.1 命令执行（PowerShell）

控制项目和具体实现方式见下表：

控制项	实现方式
只读白名单（仅常规模式）	对每个以 | 分隔的文本段，仅检查段首是否为 Get、Test、Select、Where、Measure、Format、Group、Sort、Compare、ConvertTo、ConvertFrom、Out- 等只读动词开头
写操作黑名单（仅常规模式）	命令文本中出现 Remove、Set、New、Invoke、Start、Stop、Restart、Install、Uninstall、Enable、Disable、Clear、Add、Out-File、Set-Content 等动词时直接拒绝
执行环境	以 -NoProfile -NonInteractive 启动，不加载用户配置文件，不接受交互输入
超时控制（常规 / 完全访问）	常规模式 30 秒；完全访问模式 60 秒，检测到 pip 安装时 300 秒；超时或用户取消时终止整个进程树
输出限制	标准输出与错误输出合计截断至 5000 字符，防止超长输出冲击界面与上下文
授权要求	风险等级 High，每次调用强制弹窗确认

风险说明：上述规则仅在常规模式生效，且为字符串级过滤，不是 PowerShell 语法解析。完全访问模式下不再有任何命令内容限制。

9.2 文件读写沙箱

1. 写入操作被限定在用户配置的输出目录中。输出目录路径经过规范化校验检测，防止通过“..”等方式越界写入系统目录。完全访问模式下不生效；
2. 写入扩展名黑名单覆盖可执行文件、脚本、安装包与二进制文件和镜像文件（如.exe、.dll、.bat、.ps1、.cmd、.msi、.vbs、.jar、.iso等），命中即拒绝。完全访问模式下不生效；
3. 单文件读取上限1MB，超过限制则返回错误，不加载内容；完全访问模式下取消该限制，但仍受64MB文本上限、文档100MB上限约束；
4. 读取需为真实存在的文件，路径经过完整解析后校验；不可读、不存在、超限等情况返回明确错误而不抛出异常细节。

9.3 代码执行沙箱

代码执行工具依赖用户计算机上的Python环境，在独立python.exe进程中运行用户或模型生成的Python代码，为保护用户数据安全，沙箱采取以下保护措施：

1. 以正则黑名单拦截直接的网络访问（socket、urllib、requests、httpx）、进程与文件系统操作（subprocess、shutil、pathlib、os、open）、动态执行（eval、exec、compile、__import__）等语句。完全访问模式下不生效；
2. 每次执行创建独立的随机临时工作目录，执行结束后删除脚本和目录；
3. 超时：常规 10 秒，完全访问 60 秒，检测到 pip 安装或 subprocess 时 300 秒；
4. 累计输出内容不得超过100KB，超出部分丢弃并标记为截断返回给模型。

风险说明：常规模式为“尽力而为”的沙箱，非强隔离环境；完全访问模式取消全部内容限制，等价于以当前 Windows 用户权限执行任意 Python 代码。

9.4 屏幕、窗口与系统控制

1. 截图工具在捕获时排除本软件自身窗口，避免将软件界面重复摄入，对不支持窗口排除的旧版操作系统将会自动回退为临时移屏方案；
2. 窗口管理、音量与亮度调节等操作均声明为需确认工具，执行前展示目标窗口或目标数值；
3. 全局快捷键通过系统热键注册与键盘钩子实现，仅用于识别用户设定的组合键以呼出胶囊状态窗口，按键内容不会写入数据库、日志，不会进行网络传输。

9.5 完全访问模式

1. 完全访问是一个全局的、需用户显式开启的高风险开关，用于让 AI 完成常规沙箱无法覆盖的任务（如整理任意目录、安装依赖、调试本机程序）。开关状态保存于 settings.json，跨会话、跨重启持续生效。
2. 开启流程：在“设置 - 调试”中点击“启用完全访问”按钮。需依次完成三步确认：第一步说明将解除的三项限制；第二步说明可能导致的系统损坏、隐私泄露与财产损失；第三步要求用户手动输入“我承担一切后果”。确认后软件提示并自动重启，重启后生效。
3. 解除的限制：写入文件不再受输出目录与扩展名黑名单约束；读取文件取消 1MB 单次限制；Python 代码执行取消网络、文件系统、进程与动态执行黑名单；PowerShell 取消只读动词白名单与写操作动词黑名单。
4. 不解除的机制：工具授权规则不变（Medium/High 仍需确认，PowerShell 与代码执行不允许“始终允许”，覆盖已有文件时需确认）；防提示词注入的系统规范仍强制拼接；单次超时与输出截断仍生效；DPAPI 加密、软件自身请求的 TLS 校验、工具审计写入均保留。
5. 关闭方式：点击胶囊状态窗口或主窗口的“⚠完全访问”标记，或在“设置 - 调试”中点击“关闭完全访问”，确认后软件自动重启并恢复常规策略。该开关无自动失效期限，需要用户手动关闭。
6. 状态提示：胶囊状态窗口与主窗口显示红色“⚠完全访问”标记（可点击关闭）；胶囊状态窗口输入框占位文字变为“键入内容（完全访问已开启）”；“设置 - 通用”的输出目录卡片显示“完全访问已启用，工具调用不再受此约束”。
7. 开关的启用与关闭会写入一条警告级本地日志，仅记录动作与时间，不含用户数据。


十、提示词注入与不可信内容防护

在使用本软件的过程中，模型会使用工具内容，将网页、文档、剪贴板、命令输出等外部内容送入模型的上下文，存在恶意内容伪装成指令的风险，因此软件采取以下保护措施：

1. 系统级安全规范由程序在用户设置的人格提示词后强制拼接，该规范为硬编码，用户自定义的人格提示词无法覆盖或删除该部分；
2. 工具返回的网页内容、文件内容、剪贴板内容等被明确定义为“数据”而非“指令”，系统规范要求模型不得执行其中的指令性文本；
3. 模型可调用的工具集合由程序注册表规定，未注册的工具无法被调用，工具参数在执行前先由程序校验，模型无法绕过检验直接操作文件系统或进程；
4. 即使模型被诱导使用高风险工具，仍需要用户授权，在常规模式下另受白名单、黑名单限制。

注：完全访问模式下防护仍然存在，但后果显著放大：模型一旦被网页或文件内容诱导，可在无内容限制的情况下执行删除、加密、外传等操作。建议在处理来源不明的文档或网页时关闭该模式。


十一、数据完整性检验与保障

1. 启用SQLite WAL日志模式与外键约束，启动时执行 PRAGMA quick_check 进行完整性检查，异常时记录错误并终止初始化，避免程序在损坏状态下继续写入；
2. 数据库访问通过 Dapper 参数化语句或固定 SQL 完成；检查中未发现将用户输入直接拼接进 SQL 的路径；
3. settings.json采用“先写临时文件再替换目标文件”的写入方式，写入失败则不会覆盖源文件，避免产生错误的配置文件；
4. 每次加载成功后刷新 .bak 备份；主配置损坏时自动从备份中恢复，并将损坏的文件改名为 .corrupt-<时间戳> 并保存供诊断；
5. 用户可选择自行导出备份ZIP文件，包含日记、长期事实、会话、消息、待办、轮次摘要、附件元数据及附件文件；导入时校验备份内是否包含数据库文件，并检验数据库结构是否正确，否则直接拒绝。导入操作采用先暂存，后覆盖的方式，避免在程序运行过程中强制覆盖。覆盖前自动生成 .before-restore-<时间戳> 快照文件，如果覆盖失败则尝试回滚，恢复备份完成后将会清理未被引用的孤儿附件。

完全访问模式下，AI 可能通过命令直接修改或删除数据库、备份与日志，WAL、参数化查询、快照回滚等机制无法防御这种主动修改，审计记录的完整性也随之下降。


十二、日志与审计

用户在使用Luna的过程中，程序会根据使用场景，在特定的情况下向日志文件中写入日志条目，用于本地故障排查与稳定性改进。日志文件不会由该软件主动上传到远程服务器。

日志将会记录模块启动、配置加载、请求地址与模型、HTTP状态码、耗时、异常、文件路径等运行信息。正常路径不会记录完整对话内容、密钥或文件正文；部分异常路径会记录服务端返回的错误响应片段（最多 500 字符）和文件路径，用于本地排障。日志留存按天滚动，最多保留7个文件，超期文件自动删除。

完全访问开关的切换会写入一条警告级日志。完全访问模式下，日志与审计记录可被 AI 生成的命令读取、篡改或删除。

工具名称、工具调用参数摘要、授权结果、执行状态与时间写入本地数据库，并在对应的聊天记录中显示，供用户自查。
